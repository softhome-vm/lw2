# lw2 — Массивы и циклы

Работа с одномерными массивами и квадратными матрицами: `for`, `while`, `count`.

## Задания

| Файл | Тема |
|------|------|
| `task1V2.php` | Проверка, отсортирован ли массив по возрастанию |
| `task2V2.php` | Сумма элементов побочной диагонали матрицы |
| `task3V2.php` | Проверка массива на «зигзаг» (чередование возрастания/убывания) |

## Запуск

```bash
php task2V2.php
```
